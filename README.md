# Ticode Technologies

Enterprise IT, AI & Digital Transformation Company

## About

Ticode Technologies delivers enterprise-grade IT consulting, AI solutions, software development, and digital transformation services for businesses across Kuwait and the GCC region.

**Domain:** [www.ticodetech.com](https://www.ticodetech.com)

## Tech Stack

This project is built with:

- **Vite** - Fast build tool and dev server
- **React 18** - Modern UI framework
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling
- **shadcn/ui** - High-quality component library
- **Framer Motion** - Advanced animations
- **React Router** - Client-side routing
- **i18next** - Internationalization (English & Arabic)

## Development

### Prerequisites

- Node.js 18+ and npm

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run ESLint
- `npm test` - Run tests
- `npm run test:watch` - Run tests in watch mode
